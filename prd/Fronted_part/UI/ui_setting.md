# AyuChat UI 总方案

> 版本：v0.1  
> 状态：草案  
> 适用范围：Desktop / Android（Web 可作为 Desktop 子集迭代）

---

## 1. 文档目的

本文档记录 AyuChat 前端 UI 的**总设计方案**，作为各端（Desktop、Android）实现与后续细化 PRD 的统一基准。内容包括：布局结构、核心组件、视觉规范、交互原则、状态设计与业界参考。

---

## 2. 产品定位与 UI 目标

| 维度 | 方向 |
|------|------|
| 核心场景 | 1 对 1 私聊为主，群聊为二期扩展 |
| 平台优先级 | Desktop 先行 → Android 对齐 → 跨端体验一致 |
| 设计风格 | 简洁、信息清晰、低视觉噪音；偏现代 IM，非游戏/社区重度风格 |
| 体验目标 | 消息阅读效率高、输入流畅、状态反馈明确（发送/已读/失败） |

---

## 3. 整体信息架构

### 3.1 桌面端（Desktop）— 双栏布局

业界通用模型：**左侧会话列表 + 右侧聊天区**。

```
┌─────────────────┬────────────────────────────────────────┐
│   会话列表       │  顶栏：头像 / 名称 / 在线状态 / 更多操作   │
│   (固定宽度)     ├────────────────────────────────────────┤
│                 │                                        │
│  [搜索]          │           消息流（可滚动）               │
│  [会话项 × N]    │                                        │
│                 ├────────────────────────────────────────┤
│                 │  输入区：附件 + 多行输入 + 表情 + 发送      │
└─────────────────┴────────────────────────────────────────┘
```

**参考**：WhatsApp Web、Telegram Desktop、微信 PC 版。

| 区域 | 职责 |
|------|------|
| 会话列表栏 | 展示会话、未读、预览、搜索、置顶 |
| 聊天顶栏 | 当前会话身份、操作入口（详情、搜索消息等） |
| 消息流 | 气泡消息、系统消息、时间分组 |
| 输入区 | 文本输入、附件、表情、发送 |

**栏宽建议**：

- 会话列表：280–320px（可拖拽调整，最小 240px）
- 聊天区：弹性占满剩余宽度

### 3.2 移动端（Android）— 全屏导航

- **主界面**：会话列表（全屏）
- **二级界面**：聊天页（全屏，左上角返回）
- **可选 Tab**（后期）：聊天 / 通讯录 / 我

与 Desktop 共用同一套组件语义，布局改为单栏栈式导航。

### 3.3 空状态

| 场景 | 表现 |
|------|------|
| 无选中会话（Desktop） | 右侧展示品牌插画 + 「选择或开始聊天」 |
| 无会话 | 列表区空状态 + 引导「发起聊天」 |
| 新会话无消息 | 消息区居中提示「打个招呼吧」 |

## 4. 核心页面与模块

### 4.1 会话列表项（Conversation Item）

```
[头像]  名称                          时间
        最后一条消息预览...            [未读角标]
```

| 元素 | 规范 |
|------|------|
| 头像 | 圆形，40–48px（列表），支持在线状态小圆点 |
| 名称 | 单行截断，加粗或 medium |
| 预览 | 单行截断；@我、草稿用 accent 色前缀 |
| 时间 | 右对齐，次要文字色，今天显示 HH:mm，更早显示日期 |
| 未读 | 数字角标或圆点；置顶会话背景略区分 |

**排序**：置顶优先 → 最后消息时间倒序。

### 4.2 消息流（Message List）

#### 布局原则

- 新消息在底部；进入会话默认滚到最新
- 向上滚动加载历史（分页 / 虚拟列表）
- 同一发送者连续消息：合并间距，仅首条或末条显示头像（可选）

#### 气泡（Bubble）

| 属性 | 自己（Outgoing） | 对方（Incoming） |
|------|------------------|------------------|
| 对齐 | 右 | 左 |
| 背景 | 品牌主色 | 浅灰 / 表面色 |
| 文字 | 主色上的高对比浅色 | 主文字色 |
| 圆角 | 12–16px，可选小尾巴 | 同上 |

**间距**：消息间距 4–8px；左右边距 12–16px；气泡 max-width 约 70%。

#### 消息元信息

- **时间戳**：同组消息共用一个；或 hover / 长按显示
- **状态**（自己消息）：发送中 → 已送达 → 已读（图标或文字）
- **失败**：红色感叹号 + 点击重试

#### 消息类型（分期）

| 类型 | v1 | 说明 |
|------|----|------|
| 纯文本 | ✅ | 支持链接自动识别 |
| 系统消息 | ✅ | 居中、小号、次要色 |
| 图片 | 二期 | 缩略图 + 点击预览 |
| 文件 | 二期 | 图标 + 文件名 + 大小 |
| 语音 | 二期 | 波形 + 时长 |
| 引用回复 | 二期 | 气泡内上方引用条 |

#### 群聊扩展（二期）

- 气泡上方显示发送者昵称（小字、彩色或可配置）
- @ 提及高亮

### 4.3 输入区（Composer）

```
[+]  [  多行输入框（自适应高度）          ]  [表情]  [发送]
```

| 行为 | 规范 |
|------|------|
| Enter | Desktop：Enter 发送，Shift+Enter 换行 |
| 高度 | 最小 1 行，最大约 6 行，超出内部滚动 |
| 草稿 | 切换会话保留未发送内容 |
| 发送 | 空内容禁用发送按钮 |
| 附件 | v1 可占位；二期接图片/文件 |
| Typing | 顶栏或输入区上方：「对方正在输入…」 |

### 4.4 顶栏（Chat Header）

- 头像 + 名称 + 副标题（在线 / 最后上线时间）
- 右侧：搜索消息、会话详情、更多（…）
- 群聊：显示成员数

### 4.5 全局搜索

- 位置：会话列表顶部
- 范围：联系人名、会话预览、消息内容（需后端支持）
- 结果：联系人 / 会话 / 消息分 Tab 或分组展示

## 5. 视觉设计系统（Design Tokens）

### 5.1 色彩（建议初稿，实现时可微调）

| Token | 用途 | 浅色模式 | 深色模式 |
|-------|------|----------|----------|
| `--color-brand` | 主色、自己气泡、主按钮 | `#2563EB` | `#3B82F6` |
| `--color-bg-app` | 应用背景 | `#F3F4F6` | `#111827` |
| `--color-bg-surface` | 卡片、列表项、输入框 | `#FFFFFF` | `#1F2937` |
| `--color-bg-incoming` | 对方气泡 | `#E5E7EB` | `#374151` |
| `--color-text-primary` | 正文 | `#111827` | `#F9FAFB` |
| `--color-text-secondary` | 预览、时间 | `#6B7280` | `#9CA3AF` |
| `--color-border` | 分割线 | `#E5E7EB` | `#374151` |
| `--color-danger` | 发送失败、错误 | `#EF4444` | `#F87171` |
| `--color-unread` | 未读角标 | `#EF4444` | `#F87171` |

### 5.2 字体

| 层级 | 大小 | 用途 |
|------|------|------|
| Title | 16–18px / semibold | 顶栏名称、列表名称 |
| Body | 14–16px / regular | 消息正文、输入框 |
| Caption | 12px | 时间、状态、系统消息 |
| Preview | 13–14px | 会话列表预览 |

- **Desktop**：系统 UI 字体栈（Windows: Segoe UI，macOS: SF Pro，Linux: system-ui）
- **Android**：Roboto / 思源 / 系统默认

### 5.3 间距与圆角

- **间距网格**：4px 基准（4 / 8 / 12 / 16 / 24）
- **圆角**：气泡 12px，按钮 8px，头像 50%（圆形），卡片 8px
- **列表项高度**：会话项最小 64–72px

### 5.4 阴影与层级

- 会话列表与聊天区：1px 分割线即可，少用阴影
- 弹层、下拉菜单：轻 shadow `0 4px 12px rgba(0,0,0,0.1)`
- 图片预览：全屏 overlay + 深色背景

## 6. 交互与动效

| 场景 | 行为 |
|------|------|
| 发送消息 | 乐观 UI：立即展示，失败回滚并提示 |
| 新消息到达 | 在底部时自动滚到底；用户在看历史时不强滚，显示「N 条新消息」浮条 |
| 加载历史 | 顶部 loading，保持 scroll anchor |
| 长按消息 | 复制、删除、回复（后期） |
| 切换主题 | 跟随系统 / 手动切换，tokens 统一映射 |
| 过渡 | 页面切换 200–300ms；避免过度动画 |

## 7. 状态设计清单

实现时需覆盖以下 UI 状态（每个核心页面/组件）：

- [ ] 默认
- [ ] 加载中（Skeleton / Spinner）
- [ ] 空数据
- [ ] 错误 / 网络断开（顶部 banner + 重试）
- [ ] 发送中 / 失败 / 已读
- [ ] 输入框 focus / disabled
- [ ] 深色模式

## 8. 组件清单（前端拆分）

| 组件 | 说明 |
|------|------|
| `AppShell` | 桌面双栏 / 移动单栏外壳 |
| `ConversationList` | 会话列表容器 |
| `ConversationItem` | 单条会话 |
| `ChatHeader` | 聊天顶栏 |
| `MessageList` | 虚拟滚动消息列表 |
| `MessageBubble` | 文本/媒体气泡 |
| `SystemMessage` | 系统提示 |
| `MessageStatus` | 发送状态图标 |
| `Composer` | 输入区 |
| `Avatar` | 头像 + 在线状态 | ✅ Desktop `ui/Avatar` |
| `Dialog` | 通用弹窗（遮罩 + 面板） | ✅ Desktop `ui/Dialog` |
| `ConfirmDialog` | 二次确认弹窗 | ✅ Desktop `ui/ConfirmDialog` |
| `SettingsDialog` | 设置页（左右分栏：导航 + 内容） | ✅ Desktop `SettingsComponent` |
| `UnreadBadge` | 未读角标 |
| `SearchBar` | 全局搜索 |
| `EmptyState` | 各场景空状态 |
| `ConnectionBanner` | 断线重连提示 |

**跨端策略**：同一套组件 API + 各端 Shell 布局差异；Design Tokens 统一，样式层按平台微调触控热区（Android 最小 48dp）。

## 9. 性能与工程约束

| 项 | 要求 |
|----|------|
| 长列表 | 消息列表必须使用虚拟滚动 |
| 图片 | 懒加载 + 占位图 + 渐进加载 |
| 字体 | 避免自定义 webfont 过重；系统字体优先 |
| 响应式 | Desktop 最小宽度约 768px；更窄时可折叠会话列表为抽屉 |
| Safe Area | Android 底部输入区适配键盘与安全区 |

## 10. 业界参考与差异化

### 10.1 参考产品

| 产品 | 借鉴点 |
|------|--------|
| Telegram | 简洁双栏、主题清晰、消息分组 |
| WhatsApp Web | 气泡配色、已读双勾、输入区布局 |
| 微信 PC | 会话列表信息密度、中文排版习惯 |
| Slack | 线程、Reactions（后期可参考） |
| Discord | 仅参考成员列表侧栏，不做频道树复杂度 |

### 10.2 AyuChat 差异化方向（待定）

- 品牌色与空状态插画统一 AyuChat 视觉
- 后续 `connect` 模块能力在 UI 上的呈现方式（设备/连接状态）需单独 PRD 对齐
- 不做 v1：频道、语音房、贴纸商城、复杂 embed

## 11. 分期路线图

### Phase 1 — MVP UI

- Desktop 双栏布局
- 会话列表 + 文本消息 + 输入发送
- 发送状态（发送中/失败/已送达）
- 浅色 + 深色模式
- 空状态、加载、断线 banner

### Phase 2 — 富媒体与群聊

- 图片、文件、语音消息 UI
- 群聊昵称、@、系统消息
- 引用回复、长按菜单
- 消息搜索 UI

### Phase 3 — 体验增强

- 置顶、草稿、已读回执细粒度展示
- Reactions、线程（视产品需求）
- Android 完整对齐 + 动画 polish
- 主题自定义（accent color）
